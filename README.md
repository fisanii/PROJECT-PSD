# PENGARUH SUARA FREKUENSI 432Hz DAN 440Hz TERHADAP PENURUNAN KECCEMASAN

A. Raw Data
berupa suara dengan frekuensi 432Hz dan 440Hz yang masing-masing berdurasi 7 detik.

B. Metode
Menggunakan Fast Fourier Transform (FFT) dan Power Spectral Density (PSD) dengan menghitung band power, serta peak detection untuk mengidentifikasi karakteristik sinyal pada masing-masing frekuensi.

C. Output
berupa perbandingan kedua frekuensi dalam menangani penurunan kecemasan.

NOTE: PERHITUNGAN TINGKAT KECEMASAN MENGGUNAKAN STAI YANG ASPEKK-ASPEKNYA PERLU DITINJAU LEBIH LANJUT OLEH ORANG PROFESIONAL DALAM BIDANGNYA.
